# 명도재 이명우 코스모스와 호랑이 작품전

이명우 작가의 공개 페이스북 게시물에서 직접 확인한 이미지 네 점으로 만든 온라인 전시입니다. 기존 작업실과 별도의 전시 사이트이며, 원작을 자르지 않고 보여 줍니다.

## 출처

- 가을 코스모스 연작: https://www.facebook.com/KOREA8014LEE/posts/1786675589135782/
- 명도재 SNS 호랑이 그림전: https://www.facebook.com/KOREA8014LEE/posts/1750146886121986/

각 작품의 사진 주소와 확인한 크기는 `dist/works.json`에 기록했습니다. 원본 게시 이미지의 다운로드본을 사용합니다. 다른 작가의 작품이나 새로 생성한 대체 이미지를 넣지 않았습니다. 자료 확인일은 2026년 10월 26일입니다.

## 기능

코스모스 및 호랑이 필터, 작품 확대 보기, 이전·다음 및 방향키 이동, 10초 간격의 선택형 자동 넘김, 작품별 해설과 평론, 전시 해설·평론 탭, 원본 게시물 연결, 전시 주소 복사, 반응형 화면을 제공합니다.

## 작품 정보와 원고

연작명과 번호는 전시 구분용 표기입니다. 작품별 소제목과 전시 부제, 해설·평론은 이번 전시를 위해 새로 작성했습니다. 해설과 평론은 시각적 관찰에 근거한 AI 원고입니다. 정식 작품명과 제작 연도, 실물 출력 매체와 크기는 작가 확인이 필요합니다. 공개 게시일과 실제 제작일은 구분합니다.

## 실행

정적 파일은 `dist/`에 있습니다. `python3 -m http.server 8000 --directory dist`로 실행한 뒤 `http://localhost:8000`에서 확인합니다. 글과 정보는 `works.json`, 화면은 `index.html`, 스타일은 `style.css`에서 수정합니다.
