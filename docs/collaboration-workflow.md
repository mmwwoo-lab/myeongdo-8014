# 명도재 이명우 홈페이지 제작 6단계 협업 지침

| 단계 | 업무 | 담당 범위 |
|---|---|---|
| 01 / DIRECTOR | 명도재 총괄 지시 | 작가 선정과 전시 방향, 최종 승인 |
| 02 / ARCHIVE | 작품 자료 조사 | 원본·약력·작품 정보·사용 허락 확인 |
| 03 / CURATION | 전시 기획·평론 | 전시 맥락과 작품별 해설 작성 |
| 04 / CREATION | 음악·영상 제작 | 승인된 작품과 음원을 활용한 융합 창작 |
| 05 / WEBSITE | 전시 웹 제작 | 모바일 대응 갤러리와 감상 기능 구성 |
| 06 / REVIEW | 검수·공개 | 권리·링크·재생·접근성 점검 후 승인 |

## 어디서 작업하나요?

- 공개 포트폴리오: 저장소 루트 `index.html` — 6단계 안내를 제공합니다.
- 홈페이지 제작기: `admin/index.html` → 사이드바의 **6단계 협업 작업실**.
- 실제 입력값은 `admin/collaboration.js`의 UI에서 관리하고, `admin/collaboration.css`로 표현합니다.

## 업무 인수인계 방법

1. 총괄 담당자가 전시 제목, 작가 이름, 전시 방향을 작성합니다.
2. 각 단계 카드에 담당자, 상태(대기/진행 중/검수 요청/승인 완료), 자료 링크·허락 근거, 작업 결과·승인 근거를 입력합니다.
3. `승인 완료`를 누르려면 담당자 이름과 작업 결과를 기록해야 합니다. 이는 **입력자가 적은 자기 신고형 승인 기록**이며, 실제 사용자 인증은 아닙니다.
4. **전시 프로젝트 저장**으로 지금 사용하는 브라우저에 작업물을 보관합니다. 브라우저 저장소 삭제 시 사라질 수 있으므로 **JSON 백업**도 다운로드합니다.
5. 다음 담당자가 **프로젝트 목록 → JSON 가져오기**로 같은 프로젝트를 불러옵니다. 덮어쓰거나 충돌하기 전에 이전 파일을 보관하고 최신본인지 확인해 주세요.
6. 필요하면 각 단계의 **GitHub 업무 요청서 열기**를 눌러 제목, 자료, 진행 내역이 채워진 이슈 초안에서 직접 제출합니다. 담당자는 GitHub 로그인·권한 설정에 따라 작업할 수 있습니다.
7. **협업 진행 보고서 내려받기**로 6단계 기록을 텍스트 문서로 보관합니다.

## 검수와 공개 승인

REVIEW 담당자는 다음을 점검합니다.

- [ ] 작품·사진·음원·영상 이용 허락 및 배포 권리
- [ ] 링크와 공개 주소
- [ ] 음악·영상 재생
- [ ] 모바일·태블릿 레이아웃
- [ ] 대체 텍스트·키보드 접근성

검수 다섯 항목을 모두 완료하고 담당자 이름·결과 메모를 기재해야 REVIEW를 승인 완료로 표시할 수 있습니다. 그 다음 DIRECTOR의 **최종 공개 승인**을 체크합니다. 이 기록은 **승인 증빙을 기록하도록 돕는 UI**이지, 역할 인증·디지털 서명이나 발행 권한을 강제하는 접근제어가 아닙니다. 실제 공개 버튼은 별도 권리 확인과 GitHub 쓰기 토큰을 요구합니다.

## 보안과 기술적 범위

- 사이트 자체에 계정 로그인, 실시간 다중 편집, 동기화 서버는 없습니다. **동시 공동 편집을 지원하지 않습니다.**
- GitHub 이슈는 저장소의 이슈 기능을 통해 온라인으로 공유되지만, 임의의 GitHub 사용자를 이 페이지가 인증해 승인시키는 방식은 아닙니다.
- 원본 저작물이나 비공개 연락처, 토큰, 비공개 계약서를 **공개 GitHub 이슈에 올리지 마세요.** 자료 링크도 공개에 적합한 내용만 등록해야 합니다.
- 프로젝트 JSON에도 등록한 작가 사진·작품 이미지·메모가 포함될 수 있으므로 공유 대상과 저작권을 확인하세요.
- GitHub 저장소에 파일을 올리는 일과 GitHub Pages 웹사이트를 공개하는 일은 별도의 설정입니다.

## 역할 분담의 실무 예시

DIRECTOR는 기획 목표 및 작가·전시 승인, ARCHIVE는 메타데이터·이미지 원본 검증, CURATION은 원고와 작품별 해설, CREATION은 음원·영상 제작 및 이용 허락, WEBSITE는 반응형 화면·재생 컨트롤, REVIEW는 최종 체크리스트와 공개 승인 기록을 담당합니다.
