# 전시 홈페이지 6단계 협업

| 단계 | 업무 | 담당 범위 |
|---|---|---|
| 01 / DIRECTOR | 명도재 총괄 지시 | 작가 선정과 전시 방향, 최종 승인 |
| 02 / ARCHIVE | 작품 자료 조사 | 원본·약력·작품 정보·사용 허락 확인 |
| 03 / CURATION | 전시 기획·평론 | 전시 맥락과 작품별 해설 작성 |
| 04 / CREATION | 음악·영상 제작 | 승인된 작품과 음원을 활용한 융합 창작 |
| 05 / WEBSITE | 전시 웹 제작 | 모바일 대응 갤러리와 감상 기능 구성 |
| 06 / REVIEW | 검수·공개 | 권리·링크·재생·접근성 점검 후 승인 |

제작 화면의 단계별 입력란에 담당자·상태·출처 및 허락 근거·결과와 인수인계 메모를 기록합니다. 상태는 대기, 진행 중, 검수 요청, 승인 완료를 사용합니다.

1. 작업 후 프로젝트를 저장합니다.
2. 프로젝트 백업(JSON)을 다음 담당자에게 전달합니다.
3. 다음 담당자는 프로젝트 목록의 JSON 가져오기를 사용하고 해당 프로젝트를 편집합니다.
4. 협업 진행 보고서는 별도의 텍스트 파일로 다운로드할 수 있습니다.

이 방식은 JSON으로 자료를 인수인계하는 협업입니다. 다른 기기 사이의 실시간 동기화, 사용자 인증, 외부 AI 서비스의 자동 생성은 별도 연동이 필요합니다. 승인 상태만으로 실제 공개가 이루어지지는 않습니다.
