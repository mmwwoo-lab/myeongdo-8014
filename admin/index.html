SIMPLE ART EXHIBITION

쉽게 만드는 나만의 미술 전시관

① 전시 제목과 작가 이름을 입력합니다.

② 작품 사진을 등록합니다. 여러 장을 한 번에 올려도 되고, 작품 카드를 하나씩 추가해도 됩니다. 작품명은 사진 파일명을 바탕으로 자동 입력되며 설명과 평론은 선택 사항입니다.

③ 음악 만들기 · 랜덤 재생성: 작품 이미지를 등록한 뒤 음악 버튼을 누르면 피아노 독주 · 바이올린 독주 · 클래식 앙상블 중 한 가지를 무작위로 선택합니다. 작품 제목과 이미지 정보에 따라 곡의 조성·선율·반주가 달라지고, 버튼을 다시 누르면 다른 악기로 새 음악이 만들어집니다. 결과는 약 20초의 브라우저 합성 기악곡(WAV)으로, 실제 악기 녹음이나 Suno AI 작곡은 아닙니다.

④ 영상 만들기: 「▶ 작품 실행 · 음악+영상 제작·등록」을 누르면 해당 작품에 마지막으로 생성한 음악을 사용하고, 음악이 없을 경우 랜덤으로 작곡합니다. 작품을 천천히 좌우로 움직이는 팬(Pan), 상하 틸트(Tilt), 줌 인·아웃(Zoom), 흐린 배경과 페이드 효과로 약 20초의 작품 감상 영상을 만듭니다.

⑤ 완성된 20초 영상은 이 브라우저의 IndexedDB에 저장되고 프로젝트에 등록 상태가 표시됩니다. 다시 프로젝트를 열어 감상할 수 있지만 브라우저 저장소 정리나 기기 변경 시 사라질 수 있으니 동영상 파일도 내려받아 보관해 주세요.

음악 스타일 프롬프트: 각 작품 카드에서 음악을 생성하면 선택된 악기에 맞는 Suno 프롬프트가 표시됩니다. 「Suno 스타일 프롬프트 복사」 버튼으로 복사해 사용하세요.

⑥ 「전시관 바로 보기」로 작품 영상을 확인하고, 이용 권한에 체크한 뒤 「전시 홈페이지 완성 · 다운로드」를 누릅니다. 내려받는 독립 HTML 파일에는 등록된 영상이 파일 데이터로 포함되어, 방문자가 재생 버튼을 누르면 음악과 영상이 함께 재생됩니다. 영상 전체 크기가 36MB를 넘으면 별도 업로드와 URL 연결이 필요합니다.

공개 안내: HTML 파일 다운로드는 온라인 게시가 아닙니다. 본인이 관리하는 웹 호스팅에 올려야 공개 주소가 생깁니다. 음악과 영상은 브라우저의 자동재생 정책 때문에 대개 사용자가 재생 버튼을 눌러야 시작됩니다.

고급 기능: 작가 약력, 미술평론, 작품별 추가 데이터는 선택 입력란에서 작성하세요. 고화질 MP4 제작이나 외부 영상 불러오기는 Python 메뉴에서 사용할 수 있습니다. 기존 프로젝트는 브라우저에서 계속 편집할 수 있습니다.
