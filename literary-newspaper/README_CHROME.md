# 명도재문예신문 · Chrome 외부 브라우저 연결 / MP3 시낭송 운영

## 공개 주소
https://myeongdo-literary-times-1027.vercel.app/

## 구현 변경
- `audio-tracks.js`: 1~99번 작품의 한국어 AI 낭송 MP3 미리듣기 공개 URL을 관리합니다.
- `audio-bridge.js`: 각 작품에 브라우저 표준 HTML5 `<audio controls>` 플레이어를 제공하고 기기 음성합성(TTS)과 분리합니다.
- `chrome-launcher.js`: 페이스북/인스타그램 등 앱 내 브라우저(주로 Android)에서 'Chrome에서 시낭송 듣기' 버튼을 표시합니다. Android Chrome intent URL을 **사용자가 버튼을 누를 때** 시도하고, 동작하지 않으면 URL 복사와 '외부 브라우저에서 열기' 방법을 보여 줍니다.
- `?open=poem-01`과 같은 쿼리 인자를 Chrome 진입 시 해석해 **읽던 시로 이동**합니다.

## 제한과 투명성
- 외부 웹사이트에서 방문자의 기본 브라우저를 강제 변경할 수 없습니다. Facebook 내장 브라우저가 intent 링크를 차단할 수 있어 수동 안내를 반드시 병행합니다.
- 99개 MP3는 외부 서비스의 `mcp-preview` URL로 연결되었습니다. 원시 텍스트는 대체로 500자 이내여서 미리듣기 원고에 전문을 넣었지만, 서비스 제공자가 파일을 삭제·만료시키면 재생이 중지될 수 있습니다. 장기 운영 시 원본 MP3를 정당한 이용허락과 함께 독립 스토리지에 저장하고 링크를 교체해야 합니다.
- MP3 음성은 `delicate` 합성 음색입니다. 실제 20대 전문 여성 낭송가의 녹음이라고 주장하지 않습니다.
- 시 원문과 낭송 파일의 외부 공개·재배포에 관한 권리자의 이용 허락 여부는 공개 전에 확인해야 합니다.

## 확인 항목
- 99개 MP3 링크의 HTML5 플레이어 노출 / 99편 데이터 목록 유지
- Android Facebook UA 환경: Chrome 진입 유도 배너 및 작품별 버튼 표시
- Android Chrome UA: 불필요한 안내 배너 미표시
- 깊은 링크 intent에서 `open=poem-NN`으로 작품 위치 유지
- 클릭이 실패할 때 복사 버튼 / 안내 메시지 제공

## 실제 단말기 검수 필요
Facebook 앱 및 Chrome 설치 상태·버전에 따라 브라우저 전환 허용 여부가 다릅니다. 자동화 검사만으로 Android 앱 간 전환 성공이나 실제 음성 출력까지 보장하지 않습니다.
