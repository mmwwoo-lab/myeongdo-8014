# 명도재문예신문 — 99편 시 읽기·오디오 낭송

공개 URL: https://myeongdo-literary-times-1027.vercel.app/

이성두 시인 『별꽃은 피고 지고』 4부 99편의 작품별 시 소개, 원문, 명도재 이명우의 시 해설을 제공합니다.

## 주요 기능

- 신문형 첫 화면과 4부별 시 목차, 99편 전체 검색
- 작품별 시 소개·본문·시 해설, 이전/다음 시 이동, 공유, 인쇄
- 각 시 소개 아래 오디오 시낭송: 재생/종료, 일시정지/이어 듣기, 낭송 속도 조절, 기기 한국어 음성 선택
- 짧은 음성 구간으로 나누어 이어 읽기. 각 시의 정서에 따라 고요한 배경음악을 웹 오디오로 생성
- 모바일/PC 반응형 화면

## 오디오 안내

현재 오디오는 **실제 낭송가가 녹음한 음원 파일이 아닙니다.** 기기의 SpeechSynthesis 한국어 음성과 브라우저 Web Audio를 이용합니다. 음질, 음성 종류·성별, 작동 여부는 운영체제와 브라우저별로 다릅니다. 음성이 지원되지 않는 기기는 안내 문구가 나옵니다. 브라우저는 자동 오디오 시작을 제한하므로 사용자가 재생 버튼을 눌러야 합니다.

## 파일

- `index.html`: 신문 페이지 및 메타데이터
- `styles.css`: 반응형 신문·낭송 UI
- `data.js`: 99편 작품 원문 및 해설 자료
- `app.js`: 탐색·검색·상세·인쇄·공유
- `narration.js`: 낭송·음악 재생 엔진
- `assets/*.jpg`: 신문 삽화

## 교정·권리 안내

시 원문은 사진 전사본의 교정 초안이며 출판에 앞서 대조 교정이 필요합니다. 원작의 저작권은 이성두 시인과 권리자에게 있으며 공개 전 사용 범위와 낭송·음악화 허락을 확인해야 합니다.
