# 명도재문예신문 — 99편 통합 특별호

- 공개 주소: https://myeongdo-literary-times-1027.vercel.app/
- 제호: 명도재문예신문
- 기획·시 해설: 명도재 이명우
- 원시: 이성두 시인 『별꽃은 피고 지고』
- 수록: 1부 22편, 2부 22편, 3부 27편, 4부 28편(총 99편)

## 화면 구성

- 종합 1면 및 대표 시 기사
- 99편 수록 목차·검색·제1~4부 목록
- 작품별 시 소개, 원문, **시 해설**
- 이전/다음 읽기, 시 해설 모아보기, 링크 공유, 스크랩, 인쇄, 글자 크기 및 테마 변경
- 휴대전화/태블릿/PC 반응형 디자인 및 공유 메타데이터

## 기술

`index.html`, `styles.css`, `app.js`, `data.js`, `assets/*`는 의존 패키지 없이 열리는 정적 웹사이트입니다. 호스팅 서버에서는 이 파일 구성을 함께 배포해 주세요. GitHub 저장소에는 `literary-newspaper/` 하위 경로로 백업됩니다.

## 교정·저작권 주의

원시 99편은 사용자 제공 책 사진을 바탕으로 전사한 **교정 초고**입니다. 원작자 및 권리자의 온라인 전문 공개 허락 여부를 반드시 확인하고, 저작권 허락 범위가 확인되지 않았다면 원문 전문은 비공개 처리한 뒤 소개·해설 중심으로 운영해야 합니다. 표제·고유명사·문장부호를 최종 교열해 주십시오.
