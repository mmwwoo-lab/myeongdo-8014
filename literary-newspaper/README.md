# 명도재문예신문 — 시낭송 안정화판 (2026-10-28)

공개 주소: https://myeongdo-literary-times-1027.vercel.app/

이성두 시인의 『별꽃은 피고 지고』 4부 99편 시 전문·소개·시 해설과 각 작품별 합성음 기반 낭송 및 창작 배경음 구현.

## 수정 사항
- 사용자 버튼 클릭에서 브라우저 합성 음성 시작. 기존 세션이 없으면 사전 cancel() 실행하지 않아 모바일 제약을 완화.
- 74자 내외의 음성 구간으로 나눠 긴 시에서 재생이 중단되는 현상 완화.
- 기기 한국어 음성 목록 대기 / 자동 선택 / 음성 선택 기능.
- 재생 실패·미지원·권한 차단 상황에 대한 메시지 및 Chrome·삼성 인터넷 안내.
- 음성 재생과 배경음 상태·일시정지·재개·작품 이동 시 종료 처리 개선.
- CSS/JS 캐시 버전 변경으로 기존 스크립트 잔류 방지.

## 음성이 나오지 않을 때
1. 일반 Chrome 또는 삼성 인터넷에서 공개 주소 열기. (ChatGPT, 카카오톡, 페이스북 앱 내 웹뷰는 음성 합성 API가 차단될 수 있음)
2. 스마트폰 설정에서 '텍스트 읽어주기' / 한국어 TTS 엔진 및 음량 점검.
3. 시 상세에서 '시낭송 듣기' 누르기. 실패 시 나타나는 안내의 외부 브라우저 링크나 주소 복사 사용.

**한계:** 이 기능은 성우가 녹음한 오디오 파일을 저장·스트리밍하는 것이 아닙니다. 브라우저의 Web Speech API 지원 여부와 한국어 TTS 엔진·사용자 환경에 따라 음성이 재생되지 않을 수 있으며 코드만으로 모든 앱 내 웹뷰에 음성을 제공할 수는 없습니다. 모든 환경에서 확실하게 들리려면 이용 허락을 확인한 실제 MP3 음원을 99편 제작·탑재해야 합니다.
